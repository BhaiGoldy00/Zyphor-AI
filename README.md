# Zyphor AI

Zyphor AI is a beginner-friendly Python chatbot project created by BhaiGoldy00.
It is designed to interact with users through simple conversations, basic mathematical help, and fun quiz challenges.

The project was built to explore Python programming, chatbot logic, and user interaction while improving coding skills through practical learning.

## Features

* Interactive chatbot conversation
* Basic maths support
* Quiz and puzzle gameplay
* Score-based interaction
* Simple command-line interface

## Project Status

Zyphor AI is currently under development and is still in its early stages.
New features and improvements are being added continuously.
The goal is to gradually transform Zyphor AI into a more advanced and intelligent assistant in the future.

## Future Plans
